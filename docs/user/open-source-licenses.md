# Open source licenses

ZZZ Code includes third-party software and adapted assets. To read their license and attribution
notices:

- On web and desktop, open **Settings → About**, find **Open source licenses** under **Legal**,
  and select **View licenses**.
- On mobile, open **Settings → About ZZZ Code → Open source licenses**.

The page lists the version when available, license identifier, and the parts of ZZZ Code that include
or use the item. This also covers optional device tools that ZZZ Code installs on demand instead of
bundling. Select a row to read the complete notice text. Use the search field to find a package,
version, license, or app component.
